# Lead Finder — поиск клиентов без сайта через 2GIS

Личный мини-инструмент: вводишь нишу + город → получаешь список организаций
из 2GIS, отфильтрованный по признаку «нет сайта» (значит им можно продать
сайт / автоматизацию / рекламу). Без тарифов, без аккаунтов — работает
локально на твоей машине.

## 1. Получить ключ 2GIS Catalog API

1. Зарегистрируйся на https://dev.2gis.com/
2. Создай приложение/ключ для Catalog API (Places).
3. На момент написания у 2GIS есть бесплатный тестовый ключ с ограниченным
   числом запросов в сутки — точные лимиты и актуальный формат ответа
   смотри в их доке: https://docs.2gis.com/ru/api/search/places/reference
   (структура `contact_groups` в коде проверялась вручную, но 2GIS может
   её поменять — если фильтр «без сайта» вдруг перестанет работать,
   первым делом сверь ответ API с этим полем).
4. Скопируй `.env.example` в `.env` и впиши ключ:

   ```
   cp .env.example .env
   ```

   ```
   DGIS_API_KEY=твой_ключ
   ```

## 2. Установка и запуск

```bash
cd "gis-lead-finder"
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Открой http://localhost:8000 — там форма «ниша + город + сколько».

## Как это работает

- `POST /api/search` — дергает 2GIS Catalog API (`catalog.api.2gis.com/3.0/items`)
  по запросу `{ниша}, {город}`, сохраняет результаты в локальную SQLite
  (`leads.db`), помечает у каждой организации `has_website` по наличию
  контакта типа `website` в `contact_groups`.
- `GET /api/leads` — список сохранённых лидов, с фильтром «только без сайта».
- `GET /api/export` — выгрузка в CSV.

## Важное ограничение: телефон и сайт бесплатный ключ не даёт

Проверено на реальном ключе: `contact_groups` (телефон, сайт) не приходит
ни в `/3.0/items` (поиск), ни в `/3.0/items/byid` (карточка) — это платное
коммерческое поле, доступное только по отдельному тарифу/договору с 2GIS.
Из-за этого:

- Поле `has_website` в базе сейчас всегда `0` (не значит, что у организации
  реально нет сайта — значит, что этих данных просто нет). Колонку «сайт»
  из интерфейса убрал, чтобы не вводить в заблуждение.
- Инструмент честно закрывает только часть задачи: **поиск и шорт-лист**
  организаций по нише+городу (название, адрес, рубрика). Телефон/сайт
  добираешь вручную — открой организацию на 2gis.ru по названию+адресу
  или погугли. Автоматический скрейпинг карточек 2gis.ru не работает:
  сайт редиректит бот-запросы (без браузерной сессии) на антибот-заглушку,
  так что это не пять минут кода, а полноценный обход защиты — сознательно
  не стал это делать.
- Если понадобится платный тариф с контактами — писать в поддержку
  dev.2gis.com, но там это позиционируется как коммерческая лицензия на
  данные, а не просто "тариф подороже".

## Прочие ограничения (сознательно не делал)

- Нет авторизации и тарифов — инструмент для одного пользователя (тебя),
  не для перепродажи как SaaS.
- Один регион = один текстовый запрос "ниша, город", без точной привязки
  по `region_id`/координатам. Если для каких-то городов результаты будут
  нерелевантными — можно уточнить через `region_id` (2GIS отдаёт список
  регионов отдельным эндпоинтом).
