# Lead Finder — локальный поиск и скоринг потенциальных клиентов через 2GIS

Локальный веб-инструмент для сбора и первичного скоринга организаций по нише и городу. Позволяет быстро сформировать шорт-лист малого бизнеса для предложения услуг разработки сайтов, настройки рекламы или автоматизации процессов.

---

## Что реально умеет инструмент на бесплатном ключе 2GIS API

В 2GIS доступен бесплатный ключ Catalog API (Places), но у него есть важное техническое ограничение: **контактные данные (номера телефонов, email и прямые ссылки на сайты) являются платным коммерческим полем** и не возвращаются бесплатным эндпоинтом.

Вместо того чтобы делать неработающий фильтр или прибегать к нестабильному парсингу веб-версии с капчами, инструмент решает задачу через **эвристический скоринг на основе доступных открытых метрик**:

1. **Поиск организаций:** выгрузка компаний по запросу `{ниша}, {город}` через официальный 2GIS Catalog API (`catalog.api.2gis.com/3.0/items`).
2. **Скоринг масштаба по отзывам (`review_count`):**
   * **0–3 отзыва:** молодой или микробизнес — с высокой вероятностью не имеет собственного сайта и выделенного маркетолога, проще закрывается на диалог.
   * **4–10 отзывов:** локальное заведение/студия — средний приоритет.
   * **50+ отзывов / ключевые слова «сеть, холдинг»:** раскрученный бизнес или филиал крупной сети с готовой инфраструктурой — автоматически понижается в выдаче.
3. **Локальная база данных (SQLite):** сохранение компаний с защитой от дубликатов по `source_id`, возможностью ручного ввода найденного телефона и статуса обработки (*«Новый»*, *«Интересно»*, *«Отказ»*).
4. **Быстрый переход:** прямые ссылки на поиск организации в Google и 2GIS в один клик для ручного уточнения контактов.
5. **Экспорт:** выгрузка отфильтрованного шорт-листа в CSV.

---

## Архитектура и стек

* **Бэкенд:** Python 3 (FastAPI + Uvicorn + HTTPX для асинхронных запросов к API).
* **База данных:** SQLite (`leads.db`) с хранением метаданных, адресов, рубрик и статусов.
* **Фронтенд:** Vanilla HTML5, CSS и JavaScript без внешних зависимостей.
* **API:** 2GIS Places Catalog API v3.0.

## Установка и запуск

### 1. Получение ключа 2GIS Catalog API
1. Зарегистрируйтесь в кабинете разработчика: [https://dev.2gis.com/](https://dev.2gis.com/).
2. Создайте тестовый ключ для Catalog API (Places).
3. Скопируйте `.env.example` в `.env` и укажите ключ:
   ```bash
   cp .env.example .env
   ```
   ```env
   DGIS_API_KEY=ваш_ключ_2gis
   ```

### 2. Запуск приложения
```bash
# Перейдите в каталог проекта
cd gis-lead-finder

# Установите зависимости
pip install -r requirements.txt

# Запустите сервер
uvicorn app:app --reload --port 8000
```

Откройте в браузере: **`http://localhost:8000`**.

## Ограничения и честный статус

* **Не гарантирует отсутствие сайта у компании:** приложение определяет приоритет лида по эвристике (число отзывов и маркеры сетевого бизнеса), а не по гарантированному отсутствию домена, поскольку прямой контактный реестр закрыт коммерческой лицензией 2GIS.
* **Локальный инструмент:** предназначен для личной работы фрилансера или агентства на своей машине, без авторизации пользователей и SaaS-биллинга.
* **Парсинг антибот-страниц сознательно не используется:** запросы идут строго через официальный API.
